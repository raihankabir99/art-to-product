# Four Repository Combination

Integration workspace for the four requested projects.

## Source roles
- art-to-product: premium fashion/editorial product experience and visual direction.
- design-threads: motion/interaction direction and modern component patterns.
- tshirtwebsite1v0: Next.js/shadcn-style e-commerce structure and component conventions.
- art: product, shop, search, cart and business/admin component ideas.

## Integration rule
The projects use different application foundations, so they are not blindly merged. One host application is kept and selected UI/interaction patterns are ported into a unified component layer.
